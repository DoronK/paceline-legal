# paceline-legal

Hosted legal pages for the [Paceline](https://github.com/DoronK/paceline)
app, served via GitHub Pages so Google Play Console has a public URL to
link to. Kept in a separate public repo so the main app repo can stay
private.

- **Privacy policy**: https://doronk.github.io/paceline-legal/

Source of truth for this content lives in the main `paceline` repo at
`docs/privacy-policy.md` — update there first, then mirror the change
into `index.html` here and push.
