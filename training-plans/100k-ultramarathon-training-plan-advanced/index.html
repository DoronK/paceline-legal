How the plan is built

  • Four run days a week (Mon, Wed, Fri, Sun), with two short core routines added onto run days (not shown in the table). The long run is always on Sunday, race day included.
  • The Sunday long run starts at 22.5 km and builds to 48 km, then tapers over the last 3 weeks. The race is 100 km.
  • 14 back-to-back runs: the Monday after a long Sunday run is a second sizeable run, to train tired legs without a single huge run.
  • Finish-focused: there is no goal time, so effort is easy and conversational except on the quality days.
