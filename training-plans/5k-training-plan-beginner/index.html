Choosing a first 5K plan? Compare the starting sessions, running days and progression, not just the beginner label. This example starts with run/walk intervals before moving to continuous running; it is not a promise that every beginner will be ready to race on the same timetable.

How the plan is built

  • Four run days a week (Mon, Wed, Fri, Sun), with two short core routines added onto run days (not shown in the table). The long run is always on Sunday, race day included.
  • Weeks 1 to 4: every run is a timed run/walk session: a 5-minute brisk walk, then repeats of easy running with 2-minute walking breaks, then a 5-minute walk. The running grows from 8 × 1 min to 3 × 8 min.
  • Weeks 5 to 7: continuous running. The Sunday long run goes from 3.5 km to 4 km, then eases off in the final week before race day.
  • Run slowly enough to talk. Walk breaks are part of the plan, not a sign you're falling behind. If the running feels easy, run through a walk break.
